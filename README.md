# けん玉ログ

技ごとの成功回数を記録する、日本語のスマートフォン向けPWAです。記録はブラウザーの `localStorage` に保存され、アプリ画面と静的ファイルはService Workerでオフライン利用できます。アカウントやサーバーは不要です。

## 起動方法

PWAとオフライン機能を使うには、ローカルHTTPサーバーまたはHTTPSで配信してください。リポジトリのルートでNode.jsを使う場合:

```sh
npx --yes http-server . -p 8080
```

その後 `http://localhost:8080` を開きます。スマートフォンから利用する場合は、PCと同じネットワーク上の端末からアクセスできるようにサーバーを公開してください。インストールにはHTTPS（localhostを除く）が必要です。初回アクセス時にアプリのファイルを読み込むと、以降はオフラインでも利用できます。

## データについて

技と日付ごとの回数は、利用中のブラウザー・端末内に保存されます。ブラウザーのデータを消去すると記録も削除され、別端末へは同期されません。
