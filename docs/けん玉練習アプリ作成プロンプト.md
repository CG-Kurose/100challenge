# けん玉練習アプリ作成プロンプト

あなたは、スマートフォン向けアプリの設計・実装に詳しいソフトウェアエンジニアです。以下の要件を満たす、けん玉の練習記録アプリを作成してください。

### 目的
技ごとに成功回数を記録し、設定した目標回数（初期値100回）の達成を目指せるアプリです。練習者が成功するたびにボタンを押し、累計回数と日ごとの記録を確認できるようにしてください。

### 前提

- スマートフォンで使いやすい、インストール可能なPWAとして作成する。iPhone・Androidの主要ブラウザで利用できることを意識する。
- 画面表示・文言は日本語にする。
- 初期版はログイン不要とし、データは利用端末内に保存する。インターネット接続がなくても記録できるようにする。
- 既存のプロジェクトがある場合は、まず構成・技術スタック・既存の規約を確認し、それらに沿って実装する。新規プロジェクトの場合は、保守しやすい一般的な技術を選び、選定理由を簡潔に説明する。

### 必須機能

1. **技の管理**

- ユーザーが好きな数だけ技を追加できる。
- 技の名前と目標回数を設定・編集できる。目標回数の初期値は100回。
- 技の削除時は、関連する練習記録も削除されることを確認する。

2. **成功回数の記録**

- 技ごとに「成功！」などの大きく押しやすいボタンを表示し、押すたびに当日の成功回数を1増やす。
- 今日の日付は端末のローカル日付を使用する。
- 技ごとの累計、目標回数、進捗（例：23/100）、当日の回数がすぐ分かるようにする。
- 誤操作を直せるように、今日の回数を1減らす操作を用意する。0回より小さくはならない。
- 過去の日付の記録を確認・修正できるようにする。

3. **目標達成の表示**

- 累計が目標回数以上になったら「クリア」と分かる表示をする。
- 目標達成後も記録は続けられ、目標を超えた回数も保持する。
- 累計回数は日別記録の合計から算出し、表示と記録の不整合を防ぐ。

4. **記録履歴**

- 技ごとに日付別の成功回数を一覧で確認できる。
- 記録のない日は、履歴を不必要に埋めず、必要に応じて0回として扱う。

### 画面・操作性

- 最初の画面では、登録した技と各技の進捗が一覧で見える。
- 技を選ぶと、成功回数を記録する操作をすぐ行える。
- 片手で使えるように、スマートフォンの縦画面を優先し、タップ領域を十分大きくする。
- 回数、目標、日付、クリア状態を読み取りやすくし、色だけに頼らず文字やアイコンでも状態を示す。
- 技が未登録の場合は、次に何をすればよいか分かる案内と追加ボタンを表示する。

### データ・将来の拡張

- 技と日別記録を分けて管理し、少なくとも「技ID・技名・目標回数」と「技ID・日付・成功回数」を保存する。
- ブラウザを閉じたり再起動したりしても記録が残るようにする。
- 将来、日別推移などをグラフで表示できるよう、日付ごとの記録を取得しやすい構造にする。グラフ機能自体は初期版では実装しない。

### 品質要件

- 入力値を検証し、技名の空欄や0以下の目標回数などを適切に扱う。
- 保存に失敗した場合は、記録できたように見せず、ユーザーに分かる形でエラーを表示する。
- 操作中に画面が更新されても、回数が重複・消失しないようにする。
- 既存のテスト・Lint・型チェックの仕組みに合わせ、今回の機能に関係する検証を実行する。

### 完了条件

- 技を複数登録でき、それぞれ別の目標回数と記録を持てる。
- 成功ボタンを押すたびに、選択中の技の当日回数と累計が1ずつ増える。
- 日付が変わると当日回数は切り替わり、累計と過去の記録は維持される。
- 誤操作を修正でき、回数がマイナスにならない。
- 目標到達時にクリア表示となり、達成後も追加記録ができる。
- データが端末内に保存され、アプリを再度開いても残っている。
- スマートフォンの画面で主要な操作が無理なく行える。

まずプロジェクトを確認し、実装方針を短く示してから実装してください。実装後は変更点と実行した検証、その結果を報告してください。
